# Sales Dashboard Project

This portfolio-ready Excel workbook demonstrates a complete business intelligence workflow for a fictional retail company.

## Files
- Sales_Dashboard.xlsx
- Dashboard.pdf
- README.md
- data/raw_sales_data.csv
- data/cleaned_sales_data.csv
- docs/project-report.pdf

## Included sheets
- Raw Data: realistic fictional sales transactions
- Clean Data: cleaned, standardized, and calculated sales dataset
- Pivot Tables: summary analysis for region, category, and representative performance
- Dashboard: KPI cards, charts, and interactive filters
- Formula Demo: examples of common Excel formulas
- Data Dictionary: field descriptions
- Insights: business findings and recommendations
- Documentation: project notes and usage guidance

## Skills demonstrated
- Data cleaning and validation
- Pivot tables, charts, named ranges, conditional formatting, and data validation
- Excel formulas such as IF, IFS, SUMIFS, COUNTIFS, XLOOKUP, INDEX/MATCH, TEXT, ROUND, YEAR, MONTH, WEEKDAY, NETWORKDAYS, and EOMONTH
